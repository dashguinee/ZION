## Principales normes chinoises mobilisées

- **Financement / cadre** : Directives ESIA China Exim Bank (2007) ; Lignes directrices MOFCOM/MEE pour la protection de l'environnement des projets à l'étranger (2022) ; Loi de la RPC sur la prévention et le contrôle de la pollution par les déchets solides (2020).
- **Identification** : GB 34330-2017 ; série GB 5085.1 à 5085.7 ; Catalogue national des déchets dangereux (2021, codes HW).
- **Stockage / transport des déchets dangereux** : GB 18597-2001 ; GB 18598-2019 ; HJ 2025-2012 ; HJ 1259-2022 ; GB 15562.2.
- **Déchets industriels généraux / parc à résidus (boues rouges)** : GB 18599-2020 ; GB 50863-2013 ; GB 39496-2020.
- **Eaux souterraines / incinération** : GB/T 14848-2017 ; HJ 25.1 / HJ 610 ; GB 18484-2020 ; GB 18485-2014.
- **Conventions internationales** : Minamata (mercure) ; Montréal / Kigali (SAO) ; Bâle (mouvements transfrontières).
