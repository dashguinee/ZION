### 5.2 M3U Playlist Format

```m3u
#EXTM3U
#EXTINF:-1 tvg-id="beINSports1.qa" tvg-logo="URL" group-title="Sports",beIN Sports 1 HD
http://stream-url-here.m3u8
#EXTINF:-1 tvg-id="MBC1.ae" tvg-logo="URL" group-title="Entertainment",MBC 1
http://stream-url-here.m3u8
#EXTINF:-1 tvg-id="TF1.fr" tvg-logo="URL" group-title="French",TF1
http://stream-url-here.m3u8
```

**Key Fields:**
- `tvg-id`: Channel identifier for EPG
- `tvg-logo`: Channel logo URL
- `group-title`: Category grouping
- Stream URL: Direct M3U8 stream link

## 7. LEGAL & COMPLIANCE NOTES

### 7.1 Legal Landscape

**Caution:** IPTV legality varies by country in MENA region.

**Legal Services:**
- Official broadcaster apps (beIN Connect, OSN+, Shahid VIP)
- Licensed IPTV providers with content agreements
- Public domain/government channels (free-to-air)

**Gray Area:**
- Re-streaming services without explicit licenses
- M3U playlists from unknown sources
- "Too cheap to be true" subscriptions

**Illegal:**
- Pirated premium content
- Unauthorized redistribution of copyrighted streams
- Cracked/hacked IPTV panels

**User Responsibility:**
- Verify service legitimacy before subscribing
- Check local laws and regulations
- Avoid suspiciously cheap services offering premium content
- Understand copyright implications

---

### 7.2 Recommendations for Legal Use

1. **Use iptv-org playlists** - Community-verified public streams only
2. **Subscribe to official services** - beIN Connect, OSN+, MBC Shahid
3. **Verify provider licenses** - Ask for content distribution agreements
4. **Free trials before committing** - Test service quality and legitimacy
5. **Check stream stability** - Legal services have better uptime

### 8.3 Technical Integration

**M3U Playlist Aggregation:**
```javascript
// Fetch MENA playlist from iptv-org
const menaPlaylist = await fetch('https://iptv-org.github.io/iptv/regions/mena.m3u');

// Parse M3U format
const channels = parseM3U(menaPlaylist);

// Filter for quality and stability
const validChannels = channels.filter(ch => {
  return ch.quality >= 'HD' && ch.uptime > 95;
});

// Categorize by language and genre
const categorized = {
  arabic: validChannels.filter(ch => ch.language === 'ara'),
  french: validChannels.filter(ch => ch.language === 'fra'),
  sports: validChannels.filter(ch => ch.category === 'Sports'),
  news: validChannels.filter(ch => ch.category === 'News')
};
```

**EPG Integration:**

// Fetch EPG data from iptv-org/epg
const epgData = await fetch('https://iptv-org.github.io/epg/guides/[region].xml');

// Match channels with program schedules
const channelsWithEPG = channels.map(channel => ({
  ...channel,
