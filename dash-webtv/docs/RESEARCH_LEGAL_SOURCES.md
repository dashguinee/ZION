## 6. YOUTUBE API (Legal Embedding Framework)

### YouTube as Legal Content Source
- **Type:** Official video platform with robust API
- **Legality:** Using YouTube API to embed videos is LEGAL
- **Requirements:** YouTube API key (free from Google Cloud Console)

#### Key YouTube API Policies:

**Embedding Rules:**
- Minimum player size: 200x200px
- No auto-play until player is visible
- No overlays on players prohibited
- No charging users to watch content
- No incentivizing views
- Must maintain playback integrity

**Content ID for Creators:**
- African content creators can claim their content
- Participate in Content ID program
- Manage monetization and distribution

**Live Streaming API:**
- Create, update, manage live events
- Schedule broadcasts
- Associate video streams with events

**oEmbed API:**
- Simple embedding without manual code copying
- Provide URL, get embed code in JSON/XML

**Setup Process:**
1. Create Google Cloud Console project
2. Enable YouTube Data API v3
3. Generate API key
4. Use API key in application

**Partnership Opportunity:** Legal framework for embedding African creator content

**Sources:**
- [YouTube API Services Terms of Service](https://developers.google.com/youtube/terms/api-services-terms-of-service)
- [YouTube Live Streaming API Overview](https://developers.google.com/youtube/v3/live/getting-started)
- [YouTube API and API Key Explained: How to Get Started in 2025](https://www.getphyllo.com/post/youtube-api-and-api-key-explained-how-to-get-started-in-2025)

## 8. DEFUNCT PLATFORMS (Learn from History)

### Kwese TV (Closed August 2019)
- **Owner:** Econet Media (Strive Masiyiwa)
- **Launch:** January 30, 2017
- **Closure:** August 5, 2019 (crisis)
- **Coverage:** Sub-Saharan Africa

#### What They Did Right (Partnership Models):

**Mobile Operator Partnerships:**
- Safaricom (Kenya)
- MTN Uganda
- Multiple operators from Nigeria to Zimbabwe
- Created affordable video data bundles

**Technology Platform:**
- Roku Powered license agreement
- Offered cutting-edge TV at low cost

**Content Partnerships:**
- NBA (multi-year partnership, 2016-17 season)
- ESPN (exclusive licensed content)
- Kwese iflix joint venture (mix of live sports, entertainment, local content)

**Platform Strategy:**
- Multi-platform: Linear, mobile, digital
- Free-to-air TV, mobile apps, web streaming, pay TV

**Lessons:**
- Strong partnerships not enough without sustainable economics
- Multi-platform approach was sound
- Content partnerships with major brands (NBA, ESPN) valuable

- [Kwesé Sports - Wikipedia](https://en.wikipedia.org/wiki/Kwes%C3%A9_Sports)
