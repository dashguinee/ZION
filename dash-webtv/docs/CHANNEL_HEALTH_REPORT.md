## TECHNICAL FINDINGS

### Why Streams Die
1. **Credential expiration** - IPTV services rotate credentials
2. **Domain death** - Operators shut down or move
3. **Geo-blocking** - Some streams block non-local IPs
4. **Rate limiting** - Too many requests = blocked

### What Our Proxy Can Fix
- HTTP mixed content (browser blocks HTTP on HTTPS page)
- CORS issues (cross-origin requests)
- Basic geo-blocking (if proxy is in allowed region)

### What Our Proxy Cannot Fix
- Dead domains (DNS failure)
- Expired credentials (404 errors)
- Server-side IP blocks
- Content that no longer exists
